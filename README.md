# demos

A Vue 3 + TresJS/Three.js creative coding lab. Deployed as an SPA on Netlify (demos.jaimetorrealba.com).

## Stack

- Vue 3 + TypeScript + Vite
- vue-router
- Three.js + `@tresjs/core` + `@tresjs/cientos`
- ESLint (flat config) + Prettier
- pnpm

## Commands

```sh
pnpm install
pnpm dev
pnpm build
pnpm lint
pnpm format
```
